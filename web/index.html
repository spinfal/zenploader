    zendesk help desks expose an unauthenticated
          /api/v2/uploads.json endpoint used to attach files to
          tickets. zenploader posts a file (or some text) to one of those
          endpoints and hands you back the public, cdn-backed url.
    
        
    uploads are temporary - the response includes an
          expires_at timestamp. only upload content you're allowed
          to, and respect each help desk's terms of service.
